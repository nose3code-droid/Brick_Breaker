# ブロックくずし

ブラウザで遊べるブロック崩しゲームです。`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## 操作

| 操作 | マウス / タッチ | キーボード |
| --- | --- | --- |
| パドル移動 | ポインタを左右に動かす | `←` `→`（`A` `D`） |
| スタート・発射 | クリック / タップ | `Space` / `Enter` |
| 一時停止 | 「一時停止」ボタン | `P` / `Esc` |

## ルール

- ボールを落とさずにすべてのブロックを壊すとステージクリア（全5ステージ、以降はループしてスピードアップ）。
- 小さな点の数はブロックの耐久値です。灰色の斜線ブロックは壊れません。
- パドルの端で打ち返すほど角度が急になります。
- 連続でブロックを壊すとコンボ加点。ハイスコアはブラウザに保存されます。

## アイテム

| アイテム | 効果 |
| --- | --- |
| `W` ワイド | パドルが12秒間長くなる |
| `M` マルチ | ボールが3つに分裂 |
| `S` スロー | ボールが10秒間遅くなる |
| `1UP` | 残機 +1 |
