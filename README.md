# ブロックくずし

ブラウザで遊べるブロック崩しゲームです。`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## 操作

| 操作 | マウス / タッチ | キーボード |
| --- | --- | --- |
| パドル移動 | ポインタを左右に動かす | `←` `→`（`A` `D`） |
| スタート・発射 | クリック / タップ | `Space` / `Enter` |
| 一時停止 | 「一時停止」ボタン | `P` / `Esc` |

## ルール

- ボールを落とさずにすべてのブロックを壊すとステージクリア。全15ステージ。
- ステージが進むほど難しくなります（ボールが速くなる・パドルが短くなる・アイテムが出にくくなる・かたいブロックや壊れないブロックが増える）。
- 15ステージをすべてクリアすると2周目へ。周回ごとにボールがさらに速くなり、ブロックの耐久が +1 されます。
- 小さな点の数はブロックの耐久値です（最大5）。灰色の斜線ブロックは壊れません。
- パドルの端で打ち返すほど角度が急になります。
- 連続でブロックを壊すとコンボ加点。ハイスコアはブラウザに保存されます。

## アイテム

時間制のアイテムは、画面左下に残り秒数とゲージが表示されます。

| アイテム | 効果 |
| --- | --- |
| `W` ワイド | パドルが12秒間長くなる |
| `M` マルチ | ボールが3つに分裂 |
| `S` スロー | ボールが10秒間遅くなる |
| `P` かんつう | 8秒間、ボールが壊れないブロック以外を耐久に関係なく一撃で壊し、跳ね返らずに突き抜ける |
| `1UP` | 残機 +1 |
